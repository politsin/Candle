# Candle — режим Marlin

Эта ветка добавляет выбор **Firmware protocol: Marlin** в Settings → Connection.
GRBL остаётся режимом по умолчанию и работает без изменения команд.

## Подключение Lotmaxx / Marlin

Выберите один из транспортов:

- **Serial**: виртуальный `COM10`, 115200 бод.
- **Telnet**: `192.168.1.38`, порт `8888` для ESP32 Wi-Fi bridge.

Затем выберите **Firmware protocol: Marlin** и переподключитесь. Candle запросит
`M115` и `M114`; координаты в панели берутся из ответа `M114`.

## Действия в режиме Marlin

| Действие Candle | Команда Marlin |
| --- | --- |
| Home button | `G28 X Y` (XY only; never moves Z) |
| Пошаговый jog | `G21`, `G91`, короткий `G0`, затем `G90` |
| Stop jog / Hold | `M410` (quickstop) |
| Reset | `M112` (аварийный стоп) |
| Опрос координат | `M114` |

Кнопка Reset намеренно является аварийной: после `M112` Marlin должен быть
разблокирован штатной процедурой контроллера (обычно перезапуском). GRBL Ctrl-X
в режиме Marlin никогда не отправляется.

Непрерывный jog (шаг `0`) в Marlin-режиме отключён, поскольку GRBL `$J` у
Marlin отсутствует. Выберите конечный шаг, например 0.1, 1 или 5 мм.

Pause и Abort в Marlin-режиме делают безопасный быстрый стоп (`M410`), а
Abort дополнительно отправляет `M5`. Это **не** GRBL feed-hold: продолжать
остановленное задание кнопкой Resume нельзя; запустите его заново либо с
проверенной строки после повторного home.

GRBL-only элементы (Unlock, Check, Sleep, Door, Flood и overrides) скрыты.

## Лазер на этой прошивке

Перед работой с лучом вручную выбрать laser mode: `M950 S1`.
Управление — `M3 S0..1000` / `M5` (также поддерживается наша настройка
`M106 S0..1000`). Candle не включает `M950 S1` сам при подключении или старте
файла: это исключает неожиданное включение лазерного режима.

Полезные команды в Console:

```gcode
G28 X Y       ; home XY
G28 Z         ; home Z, любой из Z-концевиков
G28 X Y Z     ; полный home
M119          ; состояние концевиков
M950 S1       ; laser mode
M5            ; луч выключить
M950 S0       ; normal / PnP mode
```

Перед первой реальной работой проверить `M119`, направление каждой оси и
пошаговый jog с убранным/расфокусированным лазером и защитными очками.
